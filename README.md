# ✈️ AI Travel Planner

An AI-powered web application that helps users plan their dream trips with personalized itineraries, flight suggestions, and hotel recommendations.

---

## 🌐 Live Demo

🚀 Try the app here:  
https://travel-assistant-madebydarshan.streamlit.app/

---

## ✨ Features

- 🧠 AI-generated travel itineraries  
- ✈️ Real-time flight suggestions  
- 🏨 Hotel & restaurant recommendations  
- 🎯 Travel themes (Solo, Family, Adventure, etc.)  
- 📅 Day-wise itinerary planning  
- ⚡ Fast and interactive UI using Streamlit  

---

## 🏗️ Tech Stack

- **Frontend & UI:** Streamlit  
- **Backend Logic:** Python  
- **AI Integration:** OpenRouter (LLM)  
- **Flight Data API:** SerpAPI  
- **Environment Management:** dotenv
